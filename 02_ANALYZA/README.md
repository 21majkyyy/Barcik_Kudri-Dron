# 02 ANALÝZA – Ako funguje problematika / súčasný stav

Obsah priečinka:
- prehľad existujúcich riešení (hotové drony, otvorené firmvéry riadiacich jednotiek),
- princíp letu kvadrokoptéry a stabilizácie (IMU, PID regulácia),
- porovnanie a výber komponentov (riadiaca jednotka, motory, ESC, batéria, senzory),
- pravidlá prevádzky bezpilotných lietadiel (kategória Open).

Stav: pripravuje sa.
